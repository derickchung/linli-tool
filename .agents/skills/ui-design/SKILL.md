# LinLi Tool (鄰里工具) - 前端介面設計規範 (UI/UX Design Guide)

本規範定義 LinLi Tool 前端使用者介面 (UI) 與互動體驗 (UX) 的標準元件設計、視覺引導體系、相片比對輔助與法規微文案設計原則。

---

## 一、 設計哲學與視覺語彙

1. **設計原則**：
   - **鄰里信任感 (Community Trust)**：採用暖色系搭配專業工程沉穩色調，降低非專業居民使用工具的心理門檻。
   - **直覺低認知負擔 (Zero Confusion)**：清楚標明費用拆解、租期天數與取還狀態。
   - **防呆先於防錯 (Proactive Poka-Yoke)**：透過按鈕禁用、顯著警示框與相機引導，將用戶錯誤消滅於輸入階段。
2. **調色盤與視覺階層 (Tailwind CSS)**：
   - **主品牌色**：`amber-500` / `orange-600` (溫暖木工手作感)。
   - **成功/通過**：`emerald-600` / `green-500` (特徵核驗吻合、押金全額釋出)。
   - **調包/阻斷**：`rose-600` / `red-500` (品牌調包、非關物品立即攔截)。
   - **審核/注意**：`amber-600` / `yellow-500` (輕微刮傷磨損比例扣抵、重拍對焦提示)。

## 二、 核心視覺引導系統 (Visual Guidance System)

### 1. 45 度角銘牌拍攝引導 (Angle Guide)
- 在所有涉及相機取景之元件中，必須常駐顯著提示框：
  > 「📐 **建議拍攝角度：45度側身特寫，露出品牌 LOGO 與夾頭銘牌**」
- 介面效益：指引使用者以單張相片同時滿足「品牌防調包」與「功能結構驗收」，免除繁瑣補拍。

### 2. 殘影對齊取景框 (Ghost Overlay)
- **應用場景**：TAB 4 (Check-out 歸還驗收)。
- **實作規範**：
  - 於相機取景畫面上層疊加半透明 (Opacity 30%~40%) 的 Check-in 取件相片殘影。
  - 中央配置 4:3 或 1:1 輔助虛線框，引導借用人對齊機身輪廓。
  - 提供「切換殘影顯示/隱藏」之浮動開關按鈕。

### 3. Side-by-Side 雙圖對照面板
- **應用場景**：TAB 3 取件核驗、TAB 5 爭議調解工單。
- **配置**：
  - 左側：出借人上架基準照 (Anchor Photo)，標註發佈時間與品名。
  - 右側：現場拍攝之即時相片，標註比對狀態與 SHA-256 存證雜湊。

## 三、 雙軌體驗模式 (Demo Mode vs Prod Mode Toggle)

為兼顧利害關係人演示與工程實測，涉及相片分析之頁面必須配備**展示模式切換開關**：

1. **關閉狀態 (Prod Mode)**：
   - 呈現乾淨的檔案上傳區塊（支援拖曳、點擊選取或手機相機拍照）。
   - 保證一般用戶與 QA 團隊可上傳真實相片進行端到端演練。
2. **開啟狀態 (Demo Mode)**：
   - 展開快捷實拍情境卡片按鈕（如：Bosch 正常歸還、Makita 調包、馬克杯雜物）。
   - 點選後即時載入預設圖資並觸發比對，方便向評審或利害關係人流暢演示。

## 四、 驗收門禁反饋卡片設計

### 1. 綠色通過卡片 (Verification Pass)
- 顯示打勾圖示 (`lucide-react/CheckCircle2`)。
- 標明「特徵吻合，確認為同一實體物件」。
- 顯示計算完成之 SHA-256 存證指紋（前 8 碼 + 後 8 碼）。
- 自動解鎖推進按鈕（如「確認取件」或「結算歸還」）。

### 2. 紅色阻斷卡片 (Gate 1 Interception)
- 顯示警告圖示 (`lucide-react/AlertTriangle` 或 `XCircle`)。
- **非關物品**：標題「【非工具生活雜物】」，提示「照片辨識為生活物品（如馬克杯），並非登記出租之修繕工具。系統已阻止推進！」
- **品牌調包**：標題「【同類跨品牌調包攔截】」，提示「借出 Bosch，檢驗為牧田 Makita，銘牌不符！」
- **行為約束**：強制鎖定「確認取件」與「結算歸還」按鈕，清空 SHA-256，要求重新對焦拍攝。

## 五、 費用試算與信用分階梯視覺呈現

在工具預約彈窗 (Pre-Auth Calculation) 中：
1. **清楚拆解計費明細**：
   - 每日租金 × 租借天數 = 總租金。
   - 原始押金 × 信用分折扣率 = 實付預授權押金（明確標註信用等級如 90 分享 75% 減免）。
2. **大字號強調公式**：
   - 「**總租金 + 履約押金 = 預授權總額**」。
3. **心理防線提示**：
   - 備註微文案：「預授權僅鎖定信用額度，租期結束且工具歸還無誤後，押金即刻解除鎖定全額釋出。」

---

## 六、 金融微文案合規審核規範 (Zero Forbidden Words)

所有 UI 標籤、按鈕文字、ToolTip 與 Modal 彈窗，嚴格禁止出現保險法特許詞彙：
- ❌ **禁詞清單**：「保險」、「保費」、「理賠」。
- ✅ **法定合規專用詞**：
  - 「互助保障池」 (禁止簡稱保險)
  - 「維護保障金」 或 「維護費」 (禁止稱保費)
  - 「責任補貼」 或 「損害補償」 (禁止稱理賠)
