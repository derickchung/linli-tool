# LinLi Tool (鄰里工具) - 前端 UX 與互動體驗檢核工作流程 (UX-Check)

本工作流程定義 LinLi Tool (社區閒置工具共享平台) 各頁面與功能模組的用戶體驗 (UX)、介面防呆、視覺指引與合規微文案的標準化檢驗步驟。

---

## 檢核前置準備 (Prerequisites)

1. 確認後端服務已啟動：`http://127.0.0.1:8000` (Swagger: `/docs`)
2. 確認前端服務已啟動：`http://localhost:3000`
3. 確保測試資源庫正常載入：`frontend/public/test_assets/` (包含各品牌電鑽、梯子、馬克杯)

---

## 六大核心功能分頁檢核標準

### Step 1: 工具探索與預約試算 (TAB 1: Explore)
- [ ] **工具卡片與規格資訊**：品名、分類標籤、日租金、市場參考價、隨附配件清單是否完整呈現。
- [ ] **A2 自然語言情境搜尋**：
  - 輸入「水垢清洗」或「陽台青苔」➔ 是否推薦「高壓清洗機」與操作指引。
  - 輸入「壁掛畫框」或「牆面打孔」➔ 是否推薦「震動衝擊電鑽」、「水泥鑽頭」與水平儀。
  - 降級檢核：輸入日常修繕或模糊文字時，是否提供安全手工具保底建議。
- [ ] **費用試算彈窗 (Pre-Auth Calculation)**：
  - 租金計算：日租金 × 租借天數。
  - 信用分浮動押金：80 分享 50% 折抵、90 分享 75% 折抵、100 分享 100% 押金免除。
  - 授權總額說明：明確標註「總租金 + 履約押金 = 預授權總額」。
- [ ] **金融微文案合規**：檢查畫面是否落實 0 次違規詞（嚴禁「保險 / 保費 / 理賠」）。

---

### Step 2: D1 拍照辨識上架 (TAB 2: List)
- [ ] **相片上傳與邊緣壓縮 (Tier 0)**：
  - 上傳本機相片或點選示範相片，確認自動以 Canvas 壓縮至最長邊 768px。
  - 右上方顯示「耗費 258 Tokens (節省 93%)」提示。
- [ ] **AI 辨識預填 (Tool Recognition)**：
  - 支援四大電鑽品牌（Bosch、Makita 牧田、DeWalt 得偉、Milwaukee 美沃奇）精準識別。
  - 自動提取品名、配件清單與安全操作警語。
  - **嚴格防呆**：AI 嚴禁自動填寫價格，每日租金與原價必須留空由出借人手動定價。
- [ ] **品項一致性核對 (Consistency Verification)**：
  - 一致情境（電鑽照片 + 電鑽品名）：綠色標章「品項與照片一致」，解鎖發佈按鈕。
  - 不一致情境（梯子照片 + 電鑽品名）：顯著紅框警告「品項不一致」，強制鎖定發佈按鈕。
  - 壞照過濾（全黑/模糊）：觸發 Tier 1 0-Token 秒判，要求重新對焦拍攝。

---

### Step 3: 訂單交付與現場取件 (TAB 3: Check-in)
- [ ] **TOTP 見面安全核銷**：
  - 借用人端生成 60 秒倒數 6 碼動態 TOTP 取件碼。
  - 出借人輸入驗證碼後，訂單狀態順利推進至「已取件 (PICKED_UP)」。
- [ ] **Side-by-side 雙圖對照面板**：
  - 左側固定呈現出借人原始上架相片（基準錨點）。
  - 右側呈現現場拍照取景框，並常駐「📐 建議拍攝角度：45度側身特寫，露出品牌LOGO與夾頭銘牌」。
- [ ] **Check-in 第一道防線驗收**：
  - **非關雜物攔截**：拍攝生活馬克杯 ➔ 觸發 `INVALID_OBJECT` 紅色警告卡片，阻止推進使用中。
  - **同類品牌調包攔截**：借 Bosch 拍牧田 Makita ➔ 觸發 `TOOL_SWAP_DETECTED` 紅色警告卡片，清空 SHA-256。
  - **同物件吻合**：拍攝同物件 Bosch ➔ 顯示綠色通過卡片，生成 SHA-256 存證雜湊，自動推進至 `IN_USE`。

---

### Step 4: 歸還驗收雙圖差分 (TAB 4: Check-out)
- [ ] **殘影取景框 (Ghost Overlay)**：
  - 歸還取景框半透明疊加 Check-in 取件相片殘影，提供 45 度側面引導線。
- [ ] **展示模式開關 (Demo Mode Switch)**：
  - 關閉時：提供乾淨的檔案上傳/實拍介面，支援使用者自訂真實相片比對。
  - 開啟時：展開 5 大實拍快捷情境按鈕。
- [ ] **五大驗收情境比對判定**：
  - **情境 1 (MATCH 正常歸還)**：微量粉塵木屑 ➔ 100% 退還押金，信用分 +2。
  - **情境 2 (MINOR_DIFF 正常磨損)**：機身輕微刮傷 ➔ SPEC_04 責任比例 30% 扣抵，退還 70% 押金。
  - **情境 3 (DAMAGE_DETECTED 結構破損)**：機殼破裂/夾頭變形 ➔ 扣抵 100% 押金，超出差額由保障池補貼。
  - **情境 4 (TOOL_SWAP 品牌調包)**：調包牧田 ➔ 422 攔截，鎖定結算，要求重新拍照。
  - **情境 5 (INVALID_OBJECT 非關雜物)**：馬克杯照片 ➔ 422 攔截，要求重新拍照。

---

### Step 5: 爭議調解工單 (TAB 5: Disputes)
- [ ] **爭議案件發起**：歸還損壞或金額有異議時，可一鍵立案並凍結款項。
- [ ] **存證雙圖調閱**：即時調閱原始上架、Check-in 取件（含 SHA-256 Checksum）與 Check-out 歸還差分相片。
- [ ] **管委會/管理員仲裁**：提供「同意損害補償方案」或「駁回爭議」之操作按鈕。

---

### Step 6: 社區互助保障池 (TAB 6: Pool)
- [ ] **保障池公庫金流統計**：
  - 累計注資總額（每筆訂單 5% 維護保障金）。
  - 當前可用餘額與歷史責任補貼撥付金額。
- [ ] **透明化撥付案件清單**：顯示受補貼之工具品項、毀損部位、補貼金額與審核時間戳記。
- [ ] **文案檢核**：嚴格落實「互助保障池」、「維護費」與「責任補貼」專有名詞。
