## 2. 安全操作規範與注意事項
1. **防扭力反衝**：鑽孔時務必雙手穩定握持機身與把手，身體保持平衡，切勿單手操作以防鑽頭卡死產生反作用力扭傷手腕。
2. **避開管線**：在牆壁或地板鑽孔前，請務必先確認牆內無暗埋電線、自來水管或瓦斯管線。
3. **更換配件斷電**：更換鑽頭或起子頭前，必須先將正反轉撥鈕推至「中央鎖定檔」，或直接拔下電池，以策安全。
4. **禁止濕手操作**：嚴禁在潮濕或積水環境使用，禁止雨天室外鑽孔。

## 3. 常見操作 FAQ (U1 檢索知識點)

### Q1: 如何在磚牆或水泥牆上更換鑽尾？
**步驟解答**：
1. 先將正反轉開關切換至「中間空檔鎖定」或卸除電池，確保不會誤觸板機。
2. 一手握住電鑽夾頭後環，另一手逆時針方向旋轉自緊夾頭前爪直至開口大於鑽尾。
3. 將專用水泥鑽尾垂直插入夾頭正中央到底。
4. 順時針旋轉夾頭直至完全夾緊，並聽到「喀喀」鎖定聲響。
5. 輕拉鑽尾確認已緊固無偏擺。

### Q2: 鑽水泥牆壁需要開哪一個模式？
**步驟解答**：
請轉動電鑽前端的模式選擇環至「鐵鎚圖示（震動衝擊檔）」，並將轉速切換至 2 檔（高速），同時搭配水泥專用鎢鋼鑽頭。若是鎖螺絲請切換至「螺絲圖示（離合器扭力檔）」。

### Q3: 電池充飽電需要多久？充電器燈號代表什麼？
**步驟解答**：
原廠 12V 2.0Ah 電池使用隨附座充約 35-45 分鐘可充至 80% 快充，約 60 分鐘完全充滿。
- 充電器「綠燈閃爍」代表正在充電中。
- 充電器「綠燈常亮」代表已充飽電，可取下使用。
- 若「紅燈閃爍」表示電池過熱或故障，請暫停充電並置於通風陰涼處冷卻。

### Q4: 鑽孔時卡住轉不動該怎麼辦？
**步驟解答**：
1. 立即放開電源板機開關，切勿強行按壓板機以免馬達過載燒毀。
2. 將正反轉切換撥鈕撥至「反轉（向左箭頭）」。
3. 輕按板機以低速慢轉將鑽頭慢慢倒退退出鑽孔。
4. 清理鑽孔內木屑或磚粉後再重新嘗試。
