## 2. 安全操作規範與注意事項
1. **嚴禁噴人畜**：高壓水柱壓力極高，切勿對準人體、寵物、眼睛或脆弱植物噴射，可能造成嚴重切割傷。
2. **電器安全防水**：使用時插座請勿接觸地面積水，請使用具備接地線或防漏電開關 (GFCI/漏電斷路器) 之電源插座。
3. **排空先開水**：接妥自來水管後，**務必先開水龍頭供水並按壓噴槍排空主機內空氣（出水順暢後）**，再打開機器電源開關，嚴禁無水空轉運轉超過 15 秒（會損毀高壓泵浦）。
4. **關機釋放水壓**：使用完畢關閉電源開關後，需再次扣動噴槍板機將管路內殘存的高壓水完全洩壓，方可拆卸水管。

## 3. 常見操作 FAQ (U1 檢索知識點)

### Q1: 啟動前如何正確排空空氣以防馬達燒毀？
**步驟解答**：
1. 將自來水管確實卡入進水口快速接頭，並轉開水龍頭。
2. 在「電源開關保持 OFF」的狀態下，拿起噴槍對空曠地面持續扣住板機。
3. 等待約 10-20 秒，直到噴嘴流出穩定、無間歇氣泡的平順水流。
4. 放開噴槍板機，將主機電源開關切換至「ON」，即可開始高壓作業。

### Q2: 旋轉噴桿和扇形噴桿有什麼差別？該用哪一種？
**步驟解答**：
- **扇形可調噴桿**：水柱擴散柔和，壓力均勻，適合清洗汽車烤漆、機車車身、紗窗、木質家具，不易傷及表面塗層。
- **旋轉螺旋強力噴桿**：集中水柱呈螺旋高速旋轉衝擊，威力強大，專門用於去除水泥地板陳年黑垢、石板青苔、磚牆死角；**嚴禁洗車**以免打飛車漆。

### Q3: 為什麼開機後主機斷斷續續震動但沒有水壓？
**步驟解答**：
1. 檢查自來水水龍頭是否完全轉開，進水量不足會導致幫浦吸空。
2. 檢查進水濾網是否有泥沙阻塞，如有雜質請旋開濾網以清水沖洗乾淨。
3. 檢查進水軟管是否有被踩踏或扭折彎曲。
4. 檢查高壓管與噴槍連接處是否卡緊，有無漏水漏氣情況。

### Q4: 機器使用完畢如何收納才不會損壞？
**步驟解答**：
1. 關閉主機電源開關（切至 OFF）。
2. 關閉水源水龍頭。
3. 再次按壓高壓噴槍板機扣扳機洩壓，直到完全無水噴出。
4. 拆卸進水管與高壓軟管，排乾管內積水後整齊繞圈收納於工具箱中。
