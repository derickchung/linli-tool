## 2. 安全操作規範與注意事項
1. **確認卡榫鎖定**：每拉伸一節踏階，**必須親眼確認兩側的滑動自鎖扣鈕完全彈出並發出清脆的「喀嗒」鎖定聲**，嚴禁在卡榫未鎖定位時攀爬。
2. **地面堅實平整**：梯子必須置於水平、乾燥、無油污且堅固平整之硬質地面，嚴禁架設在紙箱、鬆軟泥地或濕滑磁磚上。
3. **安全傾斜角度**：使用直梯模式靠牆時，請保持 **4:1 的傾角法則（約 75 度）**，即高度每 4 公尺，梯腳距牆面約 1 公尺。
4. **三人不爬兩腳在內**：單人攀爬時重心需保持在兩側立柱中間，身體嚴禁探出側邊；最高兩階嚴禁站立，梯上嚴禁兩人同時攀登。

## 3. 常見操作 FAQ (U1 檢索知識點)

### Q1: 如何安全地展開與鎖定各節伸縮梯？
**步驟解答**：
1. 將梯子垂直立於平坦地面，腳踩住最下方踏板固定。
2. 雙手握住上方踏板兩側立柱，由上往下一階一階往上拉伸抽出。
3. 每一階抽出時，需確認左右兩邊的黑色鎖扣按鈕已自動向外彈出卡緊。
4. 展開完成後，以雙手重壓各階測試穩固度，確認無下陷晃動後方可攀登。

### Q2: 如何將伸縮梯安全收攏摺疊回原狀？
**步驟解答**：
1. 嚴禁將手指放在踏板橫樑與橫樑之間（預防夾手斷指意外）。
2. 一隻手扶住立柱外側，另一隻手拇指與食指同時向內滑動左右解鎖滑閥。
3. 讓上一節踏板在受控緩衝下滑，雙手握住立柱兩側依序由下而上或由上而下收攏。
4. 完全收合後，用隨附的尼龍魔鬼氈綁帶將所有梯階緊緊固定收納。

### Q3: 人字梯模式如何調整關節角度？
**步驟解答**：
1. 找到梯頂的巨型大關節轉盤鎖扣。
2. 將兩側關節中央的金屬拉桿向外拉開解鎖。
3. 將梯子兩翼展開至約 45 度人字形狀態。
4. 聽到關節內部彈簧卡榫「喀」一聲回彈，且關節鎖死不動，即完成人字梯定位。

### Q4: 爬梯時重心不穩或晃動該如何處理？
**步驟解答**：
1. 立即停止繼續向上攀爬，雙手抓緊兩側梯柱，緩慢降低重心下梯。
2. 檢查底座加寬平衡桿是否安裝妥當，四個橡膠腳墊是否完整貼合地面。
3. 若地面微有斜坡，請轉移作業位置或使用專用調平器，嚴禁在梯腳墊磚塊或木板。
